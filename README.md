# 钟乳石断面摄影测量复核台

洞穴保护组对钟乳石断面按月拍摄标准照做摄影测量复核。原系统只存照片链接、无法判断增长；
本系统把登记标尺、像素/毫米换算、双人确认与失效重算做成有状态闭环。

## 分层结构

- `domain/rules.js` —— **规则层**。纯函数、无 IO，前后端共用（Node 与浏览器同一份）。
- `domain/store.js` —— **存储层**。只管 `data/db.json` 的读写与履历追加。
- `server.js` —— 服务编排，所有写入动作强制调用规则层校验。
- `public/` —— **页面层**。看板、样点履历、标尺、复核周期、增长确认五个视图。
- `test/rules.test.js` —— 规则单元测试（`npm test`）。

## 业务规则

1. **标尺登记与锁定**：登记标尺编号与物理长度(mm)。开启复核时选在库标尺，标尺置“使用中”，
   同一标尺在该复核关闭（复核完成、标尺归库）前不能给别的样点使用；同一样点同时只允许一个进行中复核。
2. **像素/毫米换算**：换算系数 `k = 标尺物理长度(mm) ÷ 照片内标尺像素`，断面位置 = 断面像素 × k。
3. **1% 闸口**：照片缺失，或换算系数相对样点基准偏差超过 1%（边界 1.00% 放行），只进**待重拍**，
   不产生增长、不参与计算。重拍走“补拍重传”，合格后沿用原照片记录并补算增长。
4. **另一位测量员确认**：增长 = 相邻两张采用照片的断面位置差。连续两次增长**同向**
   且两次差值 **≤ 0.2mm**，且确认人不是这两张照片的拍摄人，才通过；确认同时配对通过相邻两条。
5. **失效重算**：样点基准更正、或历史拍摄读数更正，相关增长全部标记“已失效”（保留履历），
   按现有采用照片重算，新增长一律回到“待确认”。
6. **关闭复核**：无待重拍照片、待确认增长清零后才能关闭，关闭即标尺归库可再借用。

## 数据集合

| 集合 | 内容 | 关键状态 |
| --- | --- | --- |
| `points` | 样点档案 + 基准（标尺mm/像素、断面像素、换算系数） | 正常 / 复核进行中 / 待确认 / 待重拍 |
| `rods` | 标尺编号、物理长度 | 在库 / 使用中（锁定到复核） |
| `reviews` | 一次复核周期（样点 + 标尺） | 进行中 / 已关闭 |
| `shots` | 月度标准照登记与重拍 | 已采用 / 待重拍 |
| `growths` | 相邻照片增长及确认 | 待确认 / 已确认 / 已失效 |

每条记录都带 `history` 履历；列表有状态徽标，样点详情按时间线展示照片与增长履历。

## 启动

```bash
npm install
npm test     # 规则单元测试
npm start    # http://localhost:3912
```

数据保存在 `data/db.json`，已含演示数据：D-07（连续正向增长）、Y-03（回缩 + 一张偏差 2.146% 的待重拍照片）。
